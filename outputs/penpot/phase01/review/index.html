What this review establishes

This gallery loads local PNG exports. A loaded file is not a visual pass, pixel-identity claim, accessibility certification or approval. Missing exports remain visibly pending.

Static artwork cannot establish keyboard focus, screen-reader behavior, native safe areas, physical keyboard/IME behavior, text scaling, persistence or recovery. These remain implementation/runtime checks.

Source-capture comparison: five supplied views match their frozen PNGs after documented synthetic presentation alignment of the invoice footer to 137,500 and narrow catalog requested counts to zero. Narrow sales retains 368 changed pixels inside photos or within one logical pixel of photo edges, with none outside those regions. Earlier small pixel counts had concealed real amount/quantity mismatches; those were corrected explicitly. These figures describe source captures, not the native exports shown here.

Reference lettering can be outlined vectors; source strings are retained separately. Font hinting, image sampling and other native-export differences require the evidence record. No application implementation, merge, publication or release approval is implied.
