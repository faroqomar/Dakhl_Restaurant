# Electron reference boundary

This folder preserves the old app for consultation. New Flutter work belongs at the parent project root; its plan and screenshots stay under ../docs/planning/flutter-rebuild/.

docs/, outputs/, dist/ and design/ are links to shared parent folders. Do not move their targets into this folder or remove them as part of reference cleanup.
