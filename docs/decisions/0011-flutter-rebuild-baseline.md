# 0011 — إعادة بناء دفتر بـ Flutter وDart

الحالة: نطاق إعادة البناء معتمد من المالك؛ خطة التنفيذ مقترحة ومفصلة، ولم يبدأ تنفيذ Flutter. التاريخ: 2026-10-27. المصدر: طلب المالك وإجاباته في هذه المهمة.

## القرار المؤكد

- إعادة بناء دفتر باستخدام Flutter وDart، مع MVP يعمل على macOS وAndroid وiPhone.
- تشغيل محلي دون إنترنت؛ بيانات الجهاز مستقلة، مع التصدير والاستيراد للنسخ والنقل اليدوي. لا مزامنة أو دمج تلقائي بين الأجهزة.
- إعادة إنتاج التصميم والوظائف الحالية كما هي الآن. يقرر المالك التعديلات عند الوصول إلى كل مرحلة؛ لا نبتكر تعديلات مسبقة.
- تصدير ومشاركة PDF والطباعة العادية من النظام؛ لا تكامل طابعة حرارية ضمن الطلب الحالي.
- يبقى نطاق المطعم الواحد والقواعد المالية وحفظ التاريخ والنسخ القديمة سارياً، بما فيه حفظ سجلات العمال التاريخية دون إعادة واجهتها المحذوفة.

## السبب

يريد المالك خطة كاملة مقسمة إلى ميزات مع صور مرجعية لكل مرحلة، حتى تصل إعادة البناء إلى MVP عملي يحافظ على تصميم التطبيق وسلوكه، وليس واجهات منفصلة بلا حفظ أو تحقق.
