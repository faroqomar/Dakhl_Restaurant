### Step3 execution and stopping rule

After the owner approves this plan and sends Step3, the Lead continues all authorized independent work through implementation and verification. For each slice: specification tests fail for the intended missing behavior; implement in the owning project; pass focused tests and appropriate suite; obtain independent review; fix/reverify findings; integrate exact reviewed contracts; record feature evidence and remaining gates. Do not end Step3 merely because one helper passes, a UI decision is pending, or a draft PR exists.

A blocked work item must name its missing input and dependent paths. Continue other work. When only genuinely blocked items remain, present concrete decision packets and an honest blocked checkpoint, never a completed step. Preserve current user steering. No automatic transition to Steps4/5 or merge; after a completed step, end the turn and wait for the next supplied instruction.
