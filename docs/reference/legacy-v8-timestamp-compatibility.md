# Frozen V8 timestamp compatibility

Scope: consumer-only schema1–11 timestamp validation in Dakhl_Restaurant. The frozen `electron-reference/app/ui/model.js` accepts `Date.parse`-valid strings with at most40UTF16code units. The Dart codec validates against a private adaptation of the source parser and retains the exact original string. This changes neither financial date-only policy nor account values, engine arithmetic, persistence, UI, package versions or reviewed engine consumption.

## Grammar and safeguards

Tokenization and composers follow the pinned primary source rather than regex-family assumptions. Relevant behavior includes numeric and named-month ordering, first-three-letter month keywords, AM/PM, UTC/UT/Z and US time-zone names, signed offsets, fractional/double-colon times, comments, prefix words, UTF16 whitespace and embeddedNUL termination. ES5/ISO parsing remains a distinct first pass; terminal ISO failures cannot fall back to permissive legacy parsing.

A number outside an expected seconds/minutes range can become a day component when the legacy day composer has space. A named-month composer can ignore that third component; a complete numeric date cannot. Consequently an English date can accept seconds60 or a colon timezone minute60 while its numeric equivalent rejects them. The earlier shared-range/colon-overflow assertion was incorrect and is superseded by this source-composer implementation and actual full-validator regressions.

All input is bounded at40UTF16code units. Scanner loops consume input; numerals reproduce V8's first-nine-significant-digit cap. The TimeClip instant remains within±8640000000000000milliseconds. A conservative preconstruction year bound275830 combines TimeClip's maximumyear275760 and fewer than70calendar years of signed32-second offset; it prevents host DateTime microsecond wrap for extreme years before the final TimeClip check. Offsets are applied during construction. Original timestamp text is never reformatted.

## Regression evidence and limits

The normal corpus retains324synthetic schema/entity/history cases. An additional compact4127timestamp cases are generated by the unchanged frozen full validator with only `sales[0].createdAt` changed in the all-entities-history input:4036independent date/clock/zone matrix cases,55primary-grammar probes 22scanner/Unicode/numeral/length/TimeClip cases and14expanded-year/offset cases. The compact representation reuses the fixture instead of duplicating thousands of full documents. Both accepted/rejected outcomes and exact string retention are checked.

The initial regex implementation had125known mismatches against the4091matrix/primary cases; these were preserved as RED evidence before this adaptation. Extra extreme-year probes exposed two host-construction false acceptances, also captured before their repair. Source/generator/test hashes and actual final checks live in the dated execution evidence. No known tested mismatch is waived. Finite oracle tests and a source adaptation are not a proof of every possible `Date.parse` spelling, host local-time-zone implementation or future V8 revision; independent re-review remains required.
