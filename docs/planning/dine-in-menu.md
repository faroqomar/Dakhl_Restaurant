# MENU-0002 — منيو الصالة

الحالة: مسودة منفّذة مستقلة عن مينيو العروض. التاريخ: 2026-10-17. المصدر: قائمة المالك في المحادثة وتصحيحه الصريح للمقبلات الإضافية إلى 1,500 د.ع.
